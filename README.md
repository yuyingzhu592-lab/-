# 评鉴 · 互动作品评级计算器

给同事使用的中文评审工具。没有外部依赖、账号或服务器，直接用现代浏览器打开 `index.html` 即可使用，也可把该文件发给同事。

## 评分方式

| 评分维度 | 单项范围 | 总分权重 |
| --- | --- | --- |
| 分支选项 | 1–5 分按钮 | 20% |
| 交互叙事 | 1–5 分按钮 | 20% |
| 玩法设计 | 1–5 分按钮 | 30% |
| 声画质量 | 1–5 分按钮 | 30% |

只对 **四个大指标**评分，每项点击 1、2、3、4、5 中的一个整数按钮即可。1 分为明显不足、2 分为待改进、3 分为达标、4 分为良好、5 分为优秀。未选择表示未评分。原图的小指标保留在可展开的「评分参考」内，无需分别评分。

**总分 = Σ（大指标得分 × 对应权重）**，满分 **5 分**。四项全部选择后显示综合分数，并启用保存、复制、导出和打印。总分显示两位小数。

仅设置 **S、A、B、C** 四级。默认参考分界为：S ≥ 4.5、A 为 3.5–不足 4.5、B 为 2.5–不足 3.5、C 为 1–不足 2.5。大指标和综合结果都显示等级，使用同一套可调整规则。保存的记录保留当时的分级规则。

## 功能与数据

- 四组 1–5 分按钮，点击即可评分；支持键盘方向键、Home、End 切换，Enter / 空格选中。
- 草稿自动保存在当前浏览器；最多可保存 100 条评审记录，支持重新打开和删除。
- 导出含 UTF-8 BOM 的 CSV，包含四项分数和等级、加权贡献、总分及分级规则；文本单元格防止公式注入。
- 复制评审文本，打印报告或通过浏览器另存为 PDF。
- 手机和桌面布局、键盘操作、离线使用，无外部资源请求。

数据只存于当前浏览器的 `localStorage`，不上传、不在同事间同步。清除浏览器数据、移动文件、使用不同浏览器或无痕模式可能导致记录丢失。需要留档或交接时请导出 CSV。浏览器禁止本机存储时会显示提示，仍可评分及导出。日期默认使用上海时区。

当前版本使用独立存储 `story-review-v3`。旧版十分制数据 `story-review-v1` 和逐项评分数据 `story-review-v2` 保持原样，不自动换算；检测到旧数据时，页面提供 JSON 备份下载，其中每个存储键对应原始 JSON 字符串。新旧评分不会混合。

## 本地开发

直接编辑 `index.html` 并刷新浏览器。也可用 Python 提供本地静态服务：

```sh
cd /workspace/-
python3 -m http.server 3000 --bind 0.0.0.0
```

无需安装依赖或构建。页面本身不包含任何服务器端逻辑。
